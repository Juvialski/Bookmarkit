# Book metadata and cover reports

Bookmarkit attributes provider ratings and links to their source. Aggregate
ratings do not include individual reader reviews, libraries or private user data.
Cover images are displayed from third-party source URLs and are not bundled in
the optional Hardcover offline snapshot. A source URL is not a copyright license.

If you own a displayed image or identify incorrect book metadata, report the
affected title, ISBN or source URL through the
[Bookmarkit issue tracker](https://github.com/Juvialski/Bookmarkit/issues/new).
Do not include passwords, API tokens or sensitive personal information in a public
report. The maintainer will review the specific source and remove or replace
disputed imagery where appropriate. Removing a cover must preserve the book's
identity and ratings fallback behavior.

This reporting policy does not claim that every provider-uploaded image has been
independently licensed or that a source's metadata proves image ownership.
